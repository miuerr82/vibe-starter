# flows.md

## 這份文件做什麼

- 用來定義此產品專案中的流程
- 流程是由已定義行為組成的有序步驟，用來描述事情如何一步一步發生
- 這份文件只負責排列行為順序，不重新定義角色或物件
- 流程中的每一步驟，都是將 `behaviors.md` 中已定義的行為串接起來，不在這裡重寫角色與物件參考
- 每個項目以 `### <ID> <名稱>` 為標題；ID 格式見 `AGENTS.md` 的 ID 規則，跨檔引用一律用 ID，中文名稱只作顯示
- 步驟只寫 BEH ID（可加行為名稱方便閱讀），角色與目標物件一律以 `behaviors.md` 為準

## 範例

### FLOW-20260505-alice 申請審核流程

- 目標：完成一筆申請的送出與審核
- 步驟：
  1. BEH-20260505-alice 送出申請單
  2. BEH-20260505-alice-2 受理申請單
  3. BEH-20260505-alice-3 核准申請單
- 相關物件：OBJ-20260505-alice
