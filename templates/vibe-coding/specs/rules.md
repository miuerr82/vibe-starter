# rules.md

## 這份文件做什麼

- 用來定義此產品專案中的全域規則與不變條件
- 規則是無論在哪個流程、哪個角色或哪個狀態下都必須成立的限制
- 這份文件不描述流程順序，也不替代行為定義
- 每個項目以 `### <ID> <名稱>` 為標題；ID 格式見 `AGENTS.md` 的 ID 規則，跨檔引用一律用 ID，中文名稱只作顯示

## 不知道怎麼開始時

- 可以先從「什麼事情永遠不能錯」開始想
- 也可以先從「哪些限制不管誰操作、在哪個流程都一定成立」開始整理
- 若還是不確定，可先回頭看 `objects.md`、`states.md`、`behaviors.md`，把那些會限制建立、修改、轉移、審核、刪除的條件整理成規則

### 可直接請 AI 協助的 Prompt

> 請根據我的 `objects.md`、`states.md`、`behaviors.md`、`flows.md`，幫我整理出此專案應該寫進 `rules.md` 的全域規則。請優先列出一定成立的限制與不變條件，不要把流程步驟重寫成規則，並依「資料限制」、「狀態限制」、「權限限制」、「流程限制」分類整理。

## 範例

### RULE-20260505-alice 已送出的申請單不可回到草稿

- 分類：狀態限制
- 適用對象：OBJ-20260505-alice
- 約束：OBJ-20260505-alice 一旦離開 draft，不可再轉回 draft
- 違反時處理：拒絕操作並提示原因

### RULE-20260505-alice-2 一般使用者不得審核申請單

- 分類：權限限制
- 適用對象：BEH-20260505-alice-3
- 約束：只有 ROLE-20260505-alice-2 可以執行
- 違反時處理：拒絕操作
