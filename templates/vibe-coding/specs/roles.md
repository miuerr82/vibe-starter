# roles.md

## 這份文件做什麼

- 用來定義此產品專案中的角色
- 角色是互動中的位置，用來描述誰發起行為、誰接收結果
- 這份文件不處理物件、流程或規則本身
- 每個項目以 `### <ID> <名稱>` 為標題；ID 格式見 `AGENTS.md` 的 ID 規則，跨檔引用一律用 ID，中文名稱只作顯示

## 範例

### ROLE-20260505-alice 使用者

- 定義：使用系統功能並觸發主要操作的一方
- 相關行為：BEH-20260505-alice

### ROLE-20260505-alice-2 審核者

- 定義：負責審核申請單的一方
- 相關行為：BEH-20260505-alice-3
