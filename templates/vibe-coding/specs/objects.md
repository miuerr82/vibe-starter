# objects.md

## 這份文件做什麼

- 用來定義此產品專案中的物件
- 物件是會被修改、被傳遞，或本身持有狀態的內容
- 每個物件至少應說明定義與屬性，若物件有狀態，也應一併記錄
- 每個項目以 `### <ID> <名稱>` 為標題；ID 格式見 `AGENTS.md` 的 ID 規則，跨檔引用一律用 ID，中文名稱只作顯示

## 範例

### OBJ-20260505-alice 申請單

- 定義：系統中用來表示一筆待審核、可被處理與結案的申請資料
- 屬性：
  - 申請編號
  - 申請人
  - 申請內容
  - 審核意見
- 狀態：見 `states.md` 的 OBJ-20260505-alice
- 相關行為：BEH-20260505-alice（送出）、BEH-20260505-alice-3（核准）

### OBJ-20260505-alice-2 使用者資料

- 定義：系統中用來表示使用者身分與基本資訊的物件
- 屬性：
  - 名稱
  - 電子郵件
- 狀態：無
