# behaviors.md

## 這份文件做什麼

- 用來定義此產品專案中的行為
- 行為是會造成物件狀態改變的動作
- 每個行為都應明確寫出由誰執行、作用在哪個物件上，以及造成什麼結果
- 先以最重要、最會影響狀態的行為為主，如有需要再補充更細部的行為
- 每個項目以 `### <ID> <名稱>` 為標題；ID 格式見 `AGENTS.md` 的 ID 規則，跨檔引用一律用 ID，中文名稱只作顯示
- 前狀態 / 後狀態寫成 `<OBJ ID>=<狀態 key>`，狀態 key 以 `states.md` 為準

## 範例

### BEH-20260505-alice 送出申請單

- 角色：ROLE-20260505-alice
- 目標物件：OBJ-20260505-alice
- 前狀態：OBJ-20260505-alice=draft
- 後狀態：OBJ-20260505-alice=submitted
- 結果：申請單進入待受理
- 相關規則：RULE-20260505-alice

### BEH-20260505-alice-3 核准申請單

- 角色：ROLE-20260505-alice-2
- 目標物件：OBJ-20260505-alice
- 前狀態：OBJ-20260505-alice=reviewing
- 後狀態：OBJ-20260505-alice=approved
- 結果：申請單核准並通知申請人
